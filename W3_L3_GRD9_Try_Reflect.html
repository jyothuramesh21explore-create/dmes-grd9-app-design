Stage 4 — Explicit Instruction

Teach Time: The Reflect Phase

⏱️ 10:00

In the Reflect phase, we test our code. When it doesn't work, we have a BUG. There are two main types of bugs:

1. Syntax Error

A grammar mistake in your code (like forgetting a parenthesis or misspelling a command). The computer refuses to run the program.

2. Logic Error

The code runs perfectly, but gives the wrong answer (like adding instead of subtracting). The computer doesn't know it's wrong!

🦆
Teacher Tip: Just because a program runs without crashing does NOT mean it is correct! Always trace your code. (Click the duck for a debugging secret).
Stage 5 — Teacher Model (I Do)

Code Tracing (Think-Aloud)

⏱️ 5:00

Follow along as the teacher traces this buggy grade calculator.

# Goal: Find the average of 3 grades grade1 = 100 grade2 = 100 grade3 = 100
average = grade1 + grade2 + grade3 / 3 print("Average is:", average)

Actual Output: 233.33333333333334

The Bug: Logic Error! PEMDAS divided grade3 / 3 first, then added the others (100 + 100 + 33.3).

Adjusted Code:

average = (grade1 + grade2 + grade3) / 3
