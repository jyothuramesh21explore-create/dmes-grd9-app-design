3. Concept Lab: The IPO Model & Trust

⏱ 13:00

1. Computational Problem Solving

Every app exists to solve a problem using the I-P-O model:

  • Input: Data the user gives (e.g., GPS location).
  • Process: What the algorithm does (e.g., match driver).
  • Output: What the app returns (e.g., ETA on screen).

2. UI vs. UX

UI (User Interface) is the "paint and steering wheel" (Buttons, colors, layout).

UX (User Experience) is "how smooth the car drives" (Is it fast? Is it easy? Does it solve my problem?).
